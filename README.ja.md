## インストール

1. [Releases](https://github.com/Hyunjin-Cho/ddaka/releases) から `.dmg` をダウンロードします
2. 開いたウインドウで **`닦아` を `Applications` フォルダへドラッグ**します
3. アプリケーションフォルダから起動します

**以前の `ddak-a` をお使いの場合** — v1.3 から英語名が `ddak-a` から `ddaka` に変わったため、新しいアプリは古いアプリを上書きしません。**アプリケーションフォルダにある古い `ddak-a` をゴミ箱に入れてから**、新しいアプリを移してください。許可（アクセシビリティ・入力監視）がオフになっている場合は、オンにする場所をアプリが案内します。

> ### ⚠️ 起動する前にアプリケーションフォルダへ移してください
>
> インターネットからダウンロードしたアプリをアプリケーションフォルダの**外**で起動すると、
> macOS は毎回新しい一時コピーから実行します（App Translocation）。**この一時的な場所から動いているアプリは、
> アクセシビリティと入力監視の許可を保てません** — オンにしても、次に起動するとまたオフに戻っています。
>
> **自分で**アプリケーションフォルダへ移すと、この動作が解除されます。ダウンロードフォルダやデスクトップに
> 置いたままだと、許可は何度オンにしても残りません。
>
> v1.1 からは、アプリ自身がこの状態に気づき、**許可を求める前に**お知らせしてから終了します。

初回起動時に**アクセシビリティ**と**入力監視**の許可を求めます。キーボードをブロックするには両方が必要です。

## 動作のしかた

1. 起動 →「ddaka を開始しますか？」の確認
2. 許可の確認 — **アクセシビリティ** + **入力監視**（足りなければアプリが自分で求めます）
3. 接続している**すべてのディスプレイ**を全画面のイラストで覆い、カウントダウンを始めます — 起動するたびに 10 の場面からランダムに 1 つ選ばれます（v1.3）
4. 次のうち、いちばん早いもので終わります
   - **「完了」**ボタンをクリック → すぐに終了
   - 3 分のカウントダウンが終わる → 自動で終了
   - **Cmd + Shift + 9（⌘⇧9）** → アプリ自身が検知してすぐに終了

## ショートカットひとつで起動・終了（任意）

macOS に最初から入っている**ショートカット** App でキーボードショートカットを割り当てると、アイコンをクリックせずに ddaka を起動できます。
そのキーを **⌘⇧9** にすれば、起動するキーと終了するキーが同じになります — **覚えるのは ⌘⇧9 だけです。**

1. **ショートカット**で **＋** をクリックして新しいショートカットを作ります
2. **アプリを開く** アクションを追加し、アプリに **닦아** を選びます
3. **ショートカットの詳細**（ⓘ）→ **キーボードショートカットを追加** → **⌘⇧9** を押します

これで **⌘⇧9** → 確認で **開始** → 清掃開始、清掃中に **⌘⇧9** → 終了、となります。

- 清掃中に押した ⌘⇧9 は ddaka が先に受け取るので、ショートカットが ddaka をもう一度起動することはありません
  （macOS 27.0・ショートカット 10.0 で実行ログから確認しました。ショートカット App は macOS 12 からありますが、それ以前のバージョンでは確認していません）
- ほかのキーでも起動はできますが、**終了するキーはいつでも ⌘⇧9** です

> 💡 この方法は、韓国の Naver カフェ [맥쓰사（Mac を使う人たち）](https://cafe.naver.com/inmacbook) の **봄물결（Bommulgyeol）** さんに教えていただきました。ありがとうございます！

## ブロックされるもの

| 入力 | ブロック |
|---|---|
| 内蔵キーボード | ブロックします |
| Bluetooth / USB の外付けキーボード | ブロックします |
| メディアキー（明るさ・音量など） | ブロックします |
| Touch ID キー | **通ります — macOS が処理する正常な動作です。** 1 回押すと画面がロックされ、すばやく 3 回押すと「アクセシビリティのショートカット」パネルが開きます。ロックを解除すれば清掃画面はそのまま続きます |
| 🌐（fn）キー | **通ります** — 清掃画面には入力欄がないので、押しても何も起きません |
| Cmd + Shift + 9（⌘⇧9） | アプリが受け取って**すぐに終了**します（ほかのアプリには渡しません） |
| マウス / トラックパッド | ブロックしません |

## 安全装置

キーボードをブロックするアプリでいちばん危ないのは「いつまでも解除されない」ことです。
そのため、互いに独立したしくみを何重にも重ねています。

- 3 分のカウントダウンが終わると、ふつうに終了します
- カウントダウンとは**別に動く**安全タイマーが、190 秒でもう一度終了を試みます
- そのタイマーまで失敗したときのために、**アプリ本体とは関係のないバックグラウンドの見張り役**が
  195 秒を数えてプロセスを止めます。プロセスがなくなれば、キーボードのブロックも消えます
- 終了ボタンは**すべてのディスプレイ**に表示されるので、マウスがどこにあっても押せます
- 小さな画面でも終了ボタンが欠けないよう、レイアウトは比率を保ったまま縮みます
- **2 つ同時には起動しません。** ブロックするアプリが 2 つ動いていると、終了のショートカットで片方しか終わらず、
  もう片方がブロックし続けてしまいます。macOS 27 で確認しましたが、それより前では確認していません —
  仮に防げなかったとしても、上の自動解除はそれぞれのアプリで動きます

## 困ったときは（ログ）

v1.2 から、ddaka は**清掃がどう終わったか**を macOS のログに書きます。キーボードの解除が遅れた、何かおかしかった、
というときは、ターミナルで次を実行して、その出力を [Issue](https://github.com/Hyunjin-Cho/ddaka/issues) に添えてください。

```bash
/usr/bin/log show --last 1h --predicate 'subsystem == "com.vismotive.ddaka"'
```

- `reason=` のあとの言葉が終わった理由です — `done-button`（完了ボタン）· `countdown`（3 分）· `shortcut`（⌘⇧9）·
  `safety-timer`（190 秒の安全タイマー）· `screens-gone`（ディスプレイがすべてなくなった）
- 195 秒の強制終了が働いたときは `hard kill` と出ます
- v1.3 からは、開始の行に `theme=`（どのイラストを出したか）と `art=`（読み込めたか — `false` なら無地の空色に切り替わった）も付きます
- 🔒 **キー入力は一切記録しません。** 記録するのはアプリ自身がしたことだけです — 開始と終了、終わった理由、許可の状態

## 表示言語

アプリは Mac のシステム言語に自動で合わせます。アプリ内の設定はありません。

正確には、システムの「優先する言語」のリストのうち、**このアプリが対応している言語でいちばん上にあるもの**を使います。
1 番目が対応していない言語（たとえばフランス語）で 2 番目が日本語なら、日本語で表示されます。

| システム言語 | 表示 |
|---|---|
| 한국어 | 韓国語 |
| English | 英語 |
| 日本語 | 日本語 |
| 简体中文（中国本土・シンガポール） | 簡体字中国語 |
| 繁體中文（台湾・香港・マカオ） | 繁体字中国語 |
| リストに対応言語がひとつもない | 英語 |

繁体字中国語で言語を香港・マカオにしている場合、案内に出る macOS の設定名は香港の表記（私隱與保安・輸入監察）で表示します。

文言は `.lproj` リソースではなく、ソースの `L()` 呼び出しに 5 言語を並べて書いています。
言語がひとつでも欠けた文言を足すと**ビルドが失敗する**ので、訳し忘れは起きません。

## 動作環境

- **macOS 12（Monterey）以降**
  —  メニュー → **このMacについて** で確認できます
- **Intel・Apple シリコン**
  — 1 つのユニバーサルバイナリに両方のアーキテクチャが入っているので、Mac ごとに別のファイルを選ぶ必要はありません
- アクセシビリティの許可
- 入力監視の許可 — キー入力を受け取るには、アクセシビリティとは**別に**必要です

> 配布しているビルドで確かめた値です: 最低バージョン `12.0`、アーキテクチャは両方とも `x86_64 arm64`。
> なお、**開発と検証は macOS 27 で行い、12〜26 の実機では確認していません。**
